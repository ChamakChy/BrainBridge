# BrainBridge

Peer-to-peer academic doubt-solving platform with coin rewards, live sessions, and moderation tools.

## Project Structure
- `Backend/` — Node.js, Express, MongoDB, Socket.io API
- `Frontend/` — React + Vite web application

## Initial Setup
1. Copy `Backend/.env.example` to `Backend/.env` and fill in your values.
2. Install dependencies in both `Backend/` and `Frontend/` using `npm install`.

*(More documentation will be added as features are implemented.)*
